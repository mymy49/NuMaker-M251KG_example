Detailed Description

Board Support Package header for NuMaker-M251KG and 2.8-inch TFT Touch Shield.

Declares board initialization and global driver instances for the Waveshare 2.8-inch TFT Touch Shield Rev2.1 (ST7789V LCD, XPT2046 resistive touch controller, RGB565 frame buffer brush, GUI page task manager, and touch event dispatcher).

Initializes the hardware CRC engine in CRC32 mode:

  • Polynomial mode: CRC-32 (Crc::CRC_MODE_CRC32, polynomial 0x04C11DB7)
  • Data write width: 32-bit words (Crc::CRC_DAT_LEN_32BIT)
  • Initial polynomial seed: 0xFFFFFFFF
  • Bit order reversal: Disabled (false) for both input write data and output checksum
  • Enables the AHB clock for the CRC peripheral, applies the register configuration, and enables the CRC peripheral interrupt service routine.

Initializes on-board peripherals and user LED GPIO.

Initializes on-board peripherals and EADC channels.

Configures peripheral pins and initializes hardware devices:

  1. SPI0: PA0 (MOSI), PA1 (MISO), PA2 (CLK) initialized in Master mode (Spi::MODE_MAIN).
  2. CRC: Hardware CRC32 engine initialized in 8-bit data width mode with 0xFFFFFFFF polynomial seed.
  3. LCD: PA3 (CS), PA4 (Backlight), PA6 (DC) configured; 5000-byte frame buffer allocated and display cleared to white.
  4. Touch: PC3 (CS), PC5 (IRQ) configured for XPT2046 controller and linked to the touch event dispatcher.
    See also
    lcd, brush, touch, dispatcher, spi0, crc, initializeYss
