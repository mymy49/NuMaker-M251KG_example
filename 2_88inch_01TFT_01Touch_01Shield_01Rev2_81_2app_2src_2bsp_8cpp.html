void initializeBoard ( void )

Initializes all on-board hardware peripherals for the 2.8-inch TFT Touch Shield.

Initializes on-board hardware peripherals, LED, and UART0 interface.

Initializes on-board hardware peripherals.

Initializes on-board peripherals and user LED GPIO.

Initializes on-board peripherals and EADC channels.

Initializes on-board peripherals and hardware CRC engine.

Configures peripheral pins and initializes hardware devices:

  1. SPI0: PA0 (MOSI), PA1 (MISO), PA2 (CLK) initialized in Master mode.
  2. CRC: Hardware CRC32 engine initialized with 0xFFFFFFFF polynomial seed.
  3. LCD: PA3 (CS), PA4 (Backlight), PA6 (DC) configured; frame buffer allocated and display cleared.
  4. Touch: PC3 (CS), PC5 (IRQ) configured for XPT2046 controller and linked to touch event dispatcher.
