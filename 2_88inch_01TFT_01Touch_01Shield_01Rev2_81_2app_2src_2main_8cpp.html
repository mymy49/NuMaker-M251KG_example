int main ( void )

Initializes the yss OS kernel, target board hardware peripherals, and non-volatile flash memory. Registers the page tasks into the TaskManager (logo, main menu, touch calibration, drawing app). First presents the startup logo for 5 seconds. If touch calibration data exists, advances directly to the main menu page; otherwise, launches the calibration sequence. The main thread then yields execution in an infinite loop.
