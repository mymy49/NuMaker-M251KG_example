Detailed Description

Persistent configuration data structure stored in internal flash memory.

Stores system-wide non-volatile configuration parameters including touch screen calibration coordinates and an integrity verification checksum (CRC32). Packed to ensure consistent binary layout.

Example usage:

initializeMemory();
if (!memory.touchInitFlag)
{
// Run touch calibration procedure
memory.touch.topLeftX = 3500;
memory.touch.topLeftY = 3600;
memory.touch.botRightX = 500;
memory.touch.botRightY = 450;
memory.touchInitFlag = true;
saveMemory();
}
