◆ initializeMemory()

void initializeMemory ( )

Initializes non-volatile memory and verifies data integrity.

Reads the stored memory_t structure from the last sector of internal flash memory (page index 511). Verifies data integrity by comparing the stored CRC32 against the calculated checksum. If the checksum mismatches or the data is corrupted, it resets touch parameters to their default values and immediately writes them back to flash. Finally, calls updateMemory() to propagate parameters to active drivers.
