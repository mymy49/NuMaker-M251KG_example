Detailed Description

Free-hand drawing page application with color palette and low-pass filtering.

Implements an interactive 240x280 touch drawing canvas with a 14-color bottom toolbar, an exit button ("X") returning to the main menu, and first-order low-pass filtering (Lpf) on X and Y touch coordinates for smooth free-hand line rendering.

◆ callback_draw()

void callback_draw ( PointerDevice::event_t event)

Touch callback handling free-hand drawing strokes on the canvas area.

Handles touch down and drag events on the drawing canvas:

  • On EVENT_TOUCH_DOWN: records the starting coordinate in lastEvent and seeds the X/Y low-pass filters.
  • On EVENT_TOUCH_DRAG: filters the incoming raw touch coordinates through gLpfX and gLpfY, clamps coordinates within [0..239, 0..319], draws a line segment from lastEvent to the new filtered point using the active palette color, and updates lastEvent.
    See also
    gLpfX, gLpfY, gPalette, gLastSelectedPalette, Lpf::calculate

◆ pageDisplayDrawing()

void pageDisplayDrawing ( void * param)

Task routine for the interactive drawing canvas.

Initializes drawing canvas GUI components:

  1. Acquires the LCD lock and clears the screen with a white background.
  2. Initializes the 14 palette buttons via initializePalette() and selects black (index 0) as default.
  3. Renders the 30x40 Exit ("X") button to the right of the palette toolbar.
  4. Registers touch hit-box listeners for all 14 palette buttons, the drawing canvas region, and the exit button.
  5. Enters an infinite thread yield loop while touch callbacks handle user input.
    See also
    initializePalette, callback_draw, callback_exit, dispatcher
