void Led::initialize ( void )

Initializes the GPIO pin for the on-board red LED.

Configures GPIO port B pin 14 as output mode to control the on-board red LED. Initializes the LED to an inactive (turned off) state by calling red(false).

◆ red()

void Led::red ( bool on)

Sets the on-board red LED output state.

Controls the logic level of GPIO port B pin 14. Since the on-board red LED circuit is configured as active-low, driving the pin LOW illuminates the LED, and HIGH turns it off.
