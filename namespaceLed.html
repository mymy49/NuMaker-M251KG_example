Detailed Description

Provides control routines for the on-board user LED.

Encapsulates hardware-specific GPIO configuration and active-low output control for the red status indicator LED on the NuMaker-M251KG development board.

Example usage:

#include <yss.h>
#include <dev/led.h>
int main(void)
{
initializeYss();
Led::initialize();
while (1)
{
Led::red(true);
thread::delay(500);
Led::red(false);
thread::delay(500);
}
}

void Led::initialize ( void )

Initializes the GPIO pin for the on-board red LED.

Configures GPIO port B pin 14 as push-pull output mode to drive the on-board red LED. Immediately initializes the LED to an inactive (turned off) state by calling red(false) so the LED does not glitch on startup.

void Led::red ( bool on)

Sets the on-board red LED output state.

Controls the logic level of GPIO port B pin 14. Since the on-board red LED circuit is wired in an active-low configuration (anode tied to VCC through a current-limiting resistor, cathode connected to PB14), driving the pin LOW illuminates the LED, and driving it HIGH turns it off.
