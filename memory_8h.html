Detailed Description

Non-volatile memory management and touch calibration data storage.

Declares the persistent configuration structure (memory_t) and flash storage management routines used to load, verify, apply, and save system parameters protected by a hardware CRC32 checksum.

Reads the stored memory_t structure from the last sector of internal flash memory (page index 511). Verifies data integrity by comparing the stored CRC32 against the newly calculated checksum. If the checksum mismatches or the flash page is unprogrammed, it resets touch calibration parameters to their default uncalibrated boundaries and immediately writes them back to flash. Finally, calls updateMemory() to propagate the loaded parameters to active hardware drivers.
