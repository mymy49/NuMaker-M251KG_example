◆ main()

int main ( void )

Initializes the yss OS kernel and board hardware. Spawns a background worker thread (thread_testMutexWatchdog) and repeatedly toggles the LED while locking and unlocking gMutex with 100ms intervals. When the worker thread locks gMutex indefinitely after 5 seconds, the watchdog triggers mutexWatchdogHandler().

◆ mutexWatchdogHandler()

void mutexWatchdogHandler ( void )

Handler invoked automatically when a thread locks a mutex and fails to release it within the THREAD_WATCHDOG_OVERFLOW_TIME threshold. Overrides the default reset action and blinks the indicator LED in an emergency 500ms cycle.
