Initializes drawing canvas GUI components:

  1. Clears LCD screen with white background.
  2. Initializes palette buttons and sets default color to black (palette index 0).
  3. Renders the exit ("X") button at the right of the palette toolbar.
  4. Registers touch listeners for drawing region, palette buttons, and exit button.
  5. Enters an infinite thread yield loop waiting for touch events.

Warning

Note
Calibrates top-left and bottom-right touch coordinates, then saves to flash memory.
Precondition
LCD and XPT2046 touch driver must be initialized.
Postcondition
Calibration matrix is persisted to flash and active driver is updated.
Deprecated
none

Runs the interactive 2-point touch screen calibration state machine:

  1. Prompts user to press the top-left red target point until the progress bar reaches 100%.
  2. Records the filtered ADC values for top-left (P1).
  3. Prompts user to press the bottom-right red target point until completion.
  4. Records the filtered ADC values for bottom-right (P2).
  5. Saves calibration matrix into flash memory via saveMemory(), updates runtime driver, and transitions to the main page.
    See also
    callback_calibrate, saveMemory, updateMemory, pageDisplayMainId
