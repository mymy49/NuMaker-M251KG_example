Detailed Description

GUI page task declarations, touch callbacks, and identifiers for 2.8-inch TFT Touch Shield demo.

Declares task IDs, entry functions, palette helpers, and touch event callbacks for the logo splash screen, main menu launcher, 2-point resistive touch calibration screen, and interactive free-hand drawing canvas.

void callback_calibrate ( PointerDevice::event_t event)

Touch event callback used during the 2-point resistive touch calibration sequence.

Parameters
[in]eventPointer device touch event containing touch state (EVENT_TOUCH_DOWN, EVENT_TOUCH_DRAG, EVENT_TOUCH_UP) and coordinates.
Returns
none
Author
Yoon-Ki Hong
Date
2026-11-18
Warning
Feeds raw uncalibrated ADC values from the XPT2046 driver into moving-average low-pass filters.
Note
Registered across the full 240x320 screen area while pageDisplayTouchCalibration is active.
Precondition
touch driver must be initialized and active.
Postcondition
Calibration flags and filtered X/Y ADC readings (gLpfX, gLpfY) are updated.
Deprecated
none

Handles touch events during calibration:

  • EVENT_TOUCH_DOWN: asserts gPushFlag, clears gUpFlag, and sets gFirstContactFlag to re-seed filters.
  • EVENT_TOUCH_DRAG: when gCalibratingFlag is active, seeds or updates gLpfX and gLpfY with the raw uncalibrated X/Y ADC readings from touch.getLastConvertedAdcX() / getLastConvertedAdcY().
  • EVENT_TOUCH_UP: asserts gUpFlag to signal stylus release to the calibration state machine.
    See also
    touch, gLpfX, gLpfY, XPT2046::getLastConvertedAdcX, XPT2046::getLastConvertedAdcY

void callback_draw ( PointerDevice::event_t event)

Touch callback handling free-hand drawing strokes on the canvas area.

Parameters
[in]eventTouch event containing current touch state and screen coordinates.
Returns
none
Author
Yoon-Ki Hong
Date
2026-11-18
Warning
Acquires lcd.lock() while drawing line segments onto the display.
Note
Applies a low-pass filter (Lpf) to X and Y drag coordinates to smooth resistive touch jitter.
Precondition
lcd must be initialized and callback_draw registered to the canvas area in dispatcher.
Postcondition
A smoothed line segment in the active palette color is rendered on the LCD canvas.
Deprecated
none

Handles touch down and drag events on the drawing canvas:

  • On EVENT_TOUCH_DOWN: records the starting coordinate in lastEvent and seeds the X/Y low-pass filters.
  • On EVENT_TOUCH_DRAG: filters the incoming raw touch coordinates through gLpfX and gLpfY, clamps coordinates within [0..239, 0..319], draws a line segment from lastEvent to the new filtered point using the active palette color, and updates lastEvent.
    See also
    gLpfX, gLpfY, gPalette, gLastSelectedPalette, Lpf::calculate

void pageDisplayTouchCalibration ( void * param)

Task routine for 2-point resistive touch calibration.

Parameters
[in]paramGeneric task parameter (unused, pass nullptr).
Returns
none
Author
Yoon-Ki Hong
Date
2026-11-18
Warning
User must press target points until the progress bar completes.
Note
Calibrates top-left and bottom-right touch coordinates, then saves to flash memory.
Precondition
LCD and XPT2046 touch driver must be initialized.
Postcondition
Calibration matrix is persisted to flash and active driver is updated.
Deprecated
none

Runs the interactive 2-point touch screen calibration state machine:

  1. Prompts user to press the top-left red target point until the progress bar reaches 100%.
  2. Records the filtered ADC values for top-left (P1).
  3. Prompts user to press the bottom-right red target point until completion.
  4. Records the filtered ADC values for bottom-right (P2).
  5. Saves calibration matrix into flash memory via saveMemory(), updates runtime driver, and transitions to the main page.
