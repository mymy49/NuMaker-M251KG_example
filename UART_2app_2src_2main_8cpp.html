Detailed Description

Demonstration of interrupt-driven UART echo communication and LED trigger.

Receives serial data over UART0 via interrupt-buffered ring queue, echoes received bytes back to the sender, and triggers a non-blocking 20 ms activity LED pulse.

◆ main()

int main ( void )

Initializes the yss OS kernel and board hardware. Registers an asynchronous trigger task (trigger_blinkLed) for LED activity blinking. In the main polling loop, continuously inspects the UART0 received byte count; whenever one or more bytes arrive, it fires the blink trigger, echoes the contiguous buffer segment back through UART0, and releases the processed bytes from the internal ring buffer.
