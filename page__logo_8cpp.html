Detailed Description

Startup splash screen displaying Nuvoton logo and system information.

Renders the Nuvoton corporate logo bitmap, evaluation board title, shield description, and a blinking "Example" banner using the FrameBufferRgb565LE scratchpad brush.

void pageDisplayLogo ( void * param)

Task routine displaying board logo and system startup information.

Renders the startup splash page on the 2.8-inch TFT LCD:

  1. Acquires the LCD mutex lock (lcd.lock()).
  2. Draws the Nuvoton corporate bitmap logo (NuvotonLogo) at coordinate (20, 30).
  3. Displays centered title strings "NuMaker-M251KG V1.1", "with", "2.8inch TFT Touch Shield", and "Powered by yss OS" using Font_Ubuntu_14_B.
  4. Draws "Example" using Font_Ubuntu_20_B at (20, 200) and releases the LCD lock.
  5. Enters an infinite animation loop toggling the "Example" banner every 250 milliseconds.
