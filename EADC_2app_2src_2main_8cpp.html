Detailed Description

Main application demonstration for dual-channel EADC acquisition.

Continuously reads low-pass filtered 14-bit ADC results from EADC Channel 0 (PB0) and Channel 1 (PB1) and outputs them to the debug console.

int main ( void )

Initializes the yss OS kernel and target board peripherals. In an infinite polling loop, fetches the latest filtered 14-bit digital conversion values from EADC channels 0 and 1 via eadc.getResult() and prints the pair of values to the SWD debug terminal.
